# Build Commands

```bash
./gradlew assembleDebug    # debug APK → app/build/outputs/apk/debug/app-debug.apk
./gradlew assembleRelease  # signed release APK → app/build/outputs/apk/release/app-release.apk
```

There are no lint or test commands worth running — the project has no unit tests and no custom lint config.

A `workflow_dispatch` GitHub Actions workflow lives at `.github/workflows/build.yml`. It exposes the URL, package, name, and optional icon source as inputs plus a `debug`/`release` choice. Signed release builds require `KEYSTORE_BASE64`, `KEYSTORE_PASSWORD`, `KEY_ALIAS`, and `KEY_PASSWORD` repository secrets.

# Configuration

All app-specific values live in **`app.properties`** (project root):

```properties
app.url=https://example.com/     # URL loaded on launch → BuildConfig.HOME_URL
app.package=com.example.myapp   # applicationId
app.name=My App                  # resValue string/app_name
app.icon_url=                    # optional HTTP(S) URL or local icon path
```

`app.icon_url` accepts an HTTP(S) URL, a project-relative path, or an absolute path. Relative paths start at the project root; paths entered in GitHub Actions must refer to files committed to the repository. Supported inputs include common ImageMagick formats (PNG, JPEG, WebP, GIF, BMP, ICO, SVG, AVIF, and others) plus Android Vector Drawable XML.

`app/build.gradle.kts` reads these at build time. It injects the URL and name as `BuildConfig`/resource values and wires the icon generator into every Android variant through the Variant API. **Nothing in the Kotlin source needs editing** when customizing the app.

Local icon generation needs `curl` for remote sources, ImageMagick for raster/SVG/ICO sources, and `xmllint` from `libxml2-utils` for Android Vector Drawable detection. The Actions workflow installs ImageMagick and `libxml2-utils` automatically.

For release signing, create **`keystore.properties`** (gitignored) with `storeFile`, `storePassword`, `keyAlias`, `keyPassword`. Place the `.p12` keystore at `keystore/release-signing.p12` (or adjust `storeFile`). If `keystore.properties` is absent, release builds are unsigned.

# Architecture

The entire app is a single activity: `app/src/main/java/io/github/webviewtemplate/MainActivity.kt`.

Key behaviors implemented in `MainActivity`:

- **Edge-to-edge layout** with `WindowCompat.setDecorFitsSystemWindows(window, false)` and manual inset padding applied to the root `FrameLayout`.
- **Status bar color sync**: after each page load, JS evaluates `document.body`/`documentElement` background color; `MainActivity.syncTopInsetColorWithPage()` parses the CSS color and sets the root container background + light/dark status bar icons via `WindowInsetsControllerCompat`.
- **Back navigation**: intercepts back press to call `webView.goBack()` before finishing the activity.
- **File upload**: `onShowFileChooser` builds a chooser `Intent` combining the web `<input accept>` types, a gallery picker, and a camera capture intent (using `FileProvider` with authority `${packageName}.fileprovider`). Camera temp files are stored in `cacheDir/captured/` and cleaned up on result.
- **Camera/microphone permissions**: `onPermissionRequest` checks already-granted Android runtime permissions; if missing, defers the `PermissionRequest` in `pendingWebPermissionRequest` and launches `webPermissionLauncher`, then grants/denies after the result.

Launcher icons are generated by `scripts/generate-app-icon.sh` into `app/build/generated/appIcon/res/`:

- Raster, SVG, and ICO inputs are decoded with ImageMagick. The largest frame is selected, then legacy icons for all five Android densities and API 26+ adaptive icon resources are generated.
- Android Vector Drawable XML is detected with `xmllint` and copied directly without rasterization. AAPT performs final resource validation, so references to resources absent from this project will fail the build.
- An explicitly configured URL/path is required to exist and decode successfully; failure stops the build.
- With no icon configured, local builds use the Android system default app icon (`@android:mipmap/sym_def_app_icon`). GitHub Actions first tries the app URL's root `/favicon.ico`, then uses the same system default if unavailable or invalid.
- Local icon files are Gradle task inputs, so changing their content reruns icon generation.
